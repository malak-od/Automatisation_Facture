Retrouvez en PJ des docs utiles pour la facturation :

    Facturation check : tableau pour suivre l’avancée de la facturation lorsqu’on est plusieurs à travailler dessus – également lieu des factures et TG
    Facturation avaries ERP : tuto pour faire les avaries import / prix par transporteur
    Facturation excel : tuto pour faire les fichiers calculs et import facturation par transporteur (également dispo les vidéos dans : \\192.168.5.3\Comptabilité La Ruche\$Facturation automatique\Process)
    Numéro de comptes UPS : permet de savoir si le transporteur est UPS ou UPS_COD en fonction du numéro de compte (on retrouve les chiffres / lettres des numéros de compte dans les trackings)
    Guide des services viticolis : à partir de la page 14 permet de déterminer les zones UPS en fonction pays départ et pays d’arrivée
    Avaries Juin 2026 : fait un récap des avaries en juin 2026 + comment les résoudre + explications des différentes colonnes du CSV import
    Roadmap facturation : affiche le détail des différentes étapes de facturation
    Détail surplus facture Fedex + mail question factures fedex octobre 2025 :  permet de comprendre comment Fedex nous facture sur leur fichier excel
    Concernant les surplus tarifaires des transporteurs, si vous avez des doutes les surplus 2026 sont listés dans le Wiki pour chaque transporteur : https://wikijs.intra.laruche-logistique-france.fr/e/fr/Services/Transport/Publique/Chronopost/Supplements - sinon vous les retrouvez également dans chaque contrat transporteur

 

 
 pour info voici des trackings type pour les différents transporteurs (pour pouvoir identifier les transporteurs erronés dans export des expéditions brut)

UPS : 1Z… 18 caractères

DPD : 1021… - 14 caractères

GLS : 00… - 8caractères

Colissimo 6A… ou 6C… ou 6M… ou 9M… ou CA… ou CB… ou EY…– 13 caractères

Chronopost : XF… ou XN… ou XS… ou XT… ou XY… - 13 caractères

Delivengo : LD… - 13 caractères

Fedex : 38… ou 87… - 12 caractères

TNT :  uniquement des chiffres (les 2 premiers chiffres sont normalement le département de destination du colis) – 16 caractères

Mondial Relay : commence par 7, 8 ou 9 - entre 7 et 8 caractères

Kuehne : Soit le numéro d’expédition (pour les messageries) soit 26A… - 12 caractères

Géodis : Soit 1G… 12 caractères – soit 4… (récépissé affrètement) 9… (récépissé messagerie) - 8 caractères => attention, certains peuvent être semblables aux trackings Mondial Relay

BLS : 12… ou 13… ou 14… - 5 caractères

Lettre suivie : 8700… - 14 caractères

Lettre prépa : 2L… - 13 caractères
